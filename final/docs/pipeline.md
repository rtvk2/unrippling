# Reconstruction and measurement

Input is an ordered float32 intensity stack of shape (T,H,W) in [0,1]. Core spatial warping and patch fusion also accept RGB channels after W. Flow shape is (T,H,W,2), ordered dx then dy. Every reported reconstruction uses all T observations as candidates. Stage 2 and Stage 5 estimate distinct sets of sampling coordinates. Stage 3 and Stage 4 each consume one registered stack directly.

1. **Temporal baselines.** Reduce axis zero by mean or median. The median supplies the initial optical-flow reference. A temporally biased surface can displace even the infinite-sample average.
2. **Farnebäck registration.** Four rounds use 31, 21, 15 and 11 pixel windows, four pyramid levels, scale 0.5, three inner iterations, a 7-pixel polynomial neighborhood, polynomial sigma 1.5 and 8-pixel Gaussian flow smoothing. Each round estimates f from the previous template to each original frame. OpenCV remap samples I_t(x+f_t(x)). Each registered frame undergoes one cubic interpolation. Clip intensity overshoot. Preserve signed values for vector-field interpolation. A sample center must lie inside the original pixel rectangle; replicated boundaries extend the interpolation stencil. Average valid samples, retaining the previous reference at an entirely uncovered pixel. The final reference and final ordered stack are distinct outputs. Forward/backward cycle residual e(x)=f(x)+b(x+f(x)) gives confidence exp(−||e||²/2) on valid pixels, with displacement in pixels. This measures consistency and can miss a mutually consistent wrong match.
3. **Principal component pursuit.** Place each vectorized registered observation in a column of D. Replace invalid observations with the registration reference before ordinary PCP, an explicit imputation assumption. Inexact ALM alternates singular-value shrinkage for L, elementwise shrinkage for S and a dual update for D−L−S. Lambda defaults to 1/sqrt(max(D.shape)). SVT uses eigenvectors V and square roots s of nonnegative Gram eigenvalues. Multiply D by V diag(max(s−tau,0)/s) Vᵀ on the retained subspace, using the current ALM input in place of D for each iteration. Accumulate Gram blocks in float64. Average low-rank columns, reshape and clip for evaluation. Stop at relative Frobenius residual below 1e−4 or the cap. History records which happened. D=0 has the exact zero solution. Work scales with pixels × frames² per iteration and storage with pixels × frames.
4. **Lucky patch fusion.** Use overlapping 32-square patches with stride 16 and anchor the final patch at the boundary. For each location and candidate compute average squared Sobel gradient magnitude, suppressing gradients whose stencil touches invalid samples. Min–max normalize sharpness across usable candidates. Template similarity is masked normalized cross-correlation mapped into [0,1]; constant patches receive neutral correlation. V1 scores sharpness, V2 adds similarity, V3 adds mean confidence. Raw weights 0.4/0.4/0.2. Multiply the sum by the patch’s valid fraction. Stable ranking selects ceil(0.1T) candidates or fewer if fewer have valid samples. Weight votes by score (floor 1e−6), pixel validity and the product of interior Hann samples. Normalize the accumulated numerator by the actual accumulated pixel weights. Fall back to the template only at uncovered pixels. Optional unsharp masking defaults to zero. Bright glints can generate strong gradients even with incorrect geometry.
5. **Sparse Fourier registration.** Shi–Tomasi corners in frame zero, pyramidal KLT to each original frame and reverse KLT establish trajectories. Drop failed/out-of-frame/over-one-pixel cycle matches and trajectories with fewer than 70% usable observations. Take each trajectory’s mean observed position as its reference. At the nearest coarse-grid reference point measure original minus reference xy in full-resolution pixels. Aggregate collisions by their mean and use one observation per occupied space-time cell. Long-period motion and nonrandom track loss can bias trajectory means.

   For each displacement component separately, A selects measured entries after a unitary inverse 3D FFT over time and both spatial axes. Its adjoint scatters values at those cells and takes a unitary forward FFT. Distinct selected rows give AA*=I and Lipschitz constant 1. FISTA minimizes ½||Aθ−b||²+λΣ|θ|. At extrapolated y, take y−A*(Ay−b), then phase-preserving shrinkage z max(0,1−λ/|z|). Use Beck–Teboulle momentum. Relative proximal-gradient mapping norm below 1e−4 certifies approximate stationarity; the cap is 500. Real measurements and zero initialization preserve conjugate symmetry up to roundoff. The real inverse FFT gives coarse displacement. Endpoint-aligned bilinear resampling expands it to the native restoration grid, then the same pull convention registers every original observation.

   For V3, refit to two seeded disjoint halves of the trajectories. With independent equally variable half-estimators, one quarter of their squared difference estimates the variance of their mean. Use 1/(1+||f_A−f_B||²/4) on valid pixels as a stability score. Shared systematic bias, spatial correlation and shrinkage prevent interpreting it as a calibrated probability. At fewer than eight tracks this diagnostic is unavailable. A refined field has no corresponding split diagnostic. Two additional fits are included in the timed Fourier registration when enabled.

## Relationship to published algorithms

The original proposal adapts Oreifej’s registration/low-rank architecture using Farnebäck. Lucky-region selection adapts prior work on atmospheric turbulence and water. James et al. use trajectories, an eightfold spatial reduction, YALL1 with complex displacement, spline expansion, Fourier filtering and optional local polynomial flow. Their MATLAB main first warps with CS and then warps the result with filtered residual flow. Our implementation uses direct-to-first-frame KLT, separate real xy fits with orthonormal transforms, FISTA, linear expansion and an optional polynomial refinement. The refinement estimates temporally centered residual flow d on CS-registered frames, composes d(x)+f(x+d(x)) and samples the original image once. This is a tested adaptation. Missing MATLAB parity includes their feature ensemble, filters, solver objective scaling and two-step image interpolation. ## Evaluation boundary

Ground truth enters the measurement function after reconstruction. Internal PSNR uses peak one, SSIM uses the scikit-image grayscale implementation, and LPIPS-VGG uses the official pretrained metric on three replicated intensity channels mapped to [−1,1]. All use identical floating-point images cropped by four pixels on each edge. The benchmark's eval.py scores RGB using TorchMetrics, its prediction/255 convention, both Alex and VGG LPIPS, and its own sequence aggregation. No equivalence of internal scores with its leaderboard has been established.
